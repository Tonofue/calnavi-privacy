かるナビ プライバシーポリシー

最終更新日：2026年9月24日

本ポリシーは、Androidアプリ「かるナビ」（以下「本アプリ」）における利用者情報の取り扱いを定めるものです。本アプリは Tonofue（以下「開発者」）が開発・提供しています。

1. 開発者のサーバーについて

本アプリは開発者が運営するサーバーを持ちません。利用者のカレンダーの内容・住所・設定などが開発者に送信されることはありません。

2. Googleカレンダーのデータ

利用者がGoogleアカウントで接続した場合に限り、Google Calendar API を通じて次の操作を行います。

  • カレンダー一覧と予定（タイトル・日時・場所・メモ）の読み取り（予定と移動時間の表示のため）
  • 移動予定の作成・編集・削除（利用者が本アプリで登録・操作したもののみ）
  • 移動予定用カレンダー「移動（かるナビ）」の作成（利用者が作成ボタンを押した場合のみ）

取得したデータは利用者の端末内でのみ処理・保存し、第三者への販売・広告目的での利用・人による閲覧は行いません。認証情報（トークン）は端末内に保存され、設定画面から接続を解除できます。

本アプリによる Google API から取得した情報の使用および他のアプリへの転送は、Google API サービスのユーザーデータに関するポリシー（限定使用の要件を含む）に準拠します。

3. 所要時間・地点検索・地図・天気のための外部サービス

移動時間の目安や地点の検索を行う際、出発地・目的地の住所文字列または座標を、次の外部サービスへ送信します。これらのサービスには利用者のGoogleアカウント情報や予定のタイトルは送信しません。

用途送信先
車の所要時間OSRM（router.project-osrm.org）
徒歩・自転車の所要時間OpenRouteService（api.openrouteservice.org）
公共交通の所要時間Transitous（api.transitous.org）
地点検索国土地理院（msearch.gsi.go.jp）、Photon（photon.komoot.io）、Nominatim（nominatim.openstreetmap.org）
地図の表示OpenStreetMap のタイルサーバー
天気の表示Open-Meteo（api.open-meteo.com）

各サービスでの取り扱いは、それぞれのプライバシーポリシーに従います。

4. 広告（Google AdMob）

本アプリは画面下部にバナー広告を表示するため、Google LLC の AdMob を利用しています。AdMob は広告の配信・測定のために、広告ID・端末情報・おおよその位置（IPアドレスから推定）などを収集する場合があります。詳しくは Google の広告に関するポリシー をご覧ください。広告のパーソナライズは、端末の設定（Google → 広告）から無効にできます。

5. 通知

出発前の通知を有効にした場合、通知は端末内でのみ予約・表示され、外部に送信されることはありません。

6. 端末内に保存するデータ

自宅の住所、設定、移動の記録、地点検索結果のキャッシュを端末内に保存します。本アプリをアンインストールすると削除されます。

7. 子どもの利用

本アプリは13歳未満の子どもを対象としていません。

8. 本ポリシーの変更

本ポリシーを変更する場合は、このページで告知します。
